# Hackathon-project
🕌 Garib Nawaz Website

Welcome to the comprehensive documentation for the Garib Nawaz Website, a digital web platform designed and built during a BCA (Bachelor of Computer Applications) 1st Semester Hackathon.

This project is dedicated to creating an accessible, informative, and culturally respectful online hub centered around the life, teachings, and legacy of Khwaja Moinuddin Chishti (Garib Nawaz) and the historical Ajmer Sharif Dargah.

📌 Project Overview & Purpose.

The goal of this initiative is to bridge heritage with modern web development. As first-semester computer application students, our primary objective was to apply core web technologies to address a real-world need: providing structured, easily accessible information for visitors, devotees, and researchers interested in Ajmer Sharif.

Key Objectives

Digital Accessibility: Provide global access to detailed information regarding visitors' etiquette, daily schedules, and historical context.

Cultural Preservation: Document the rich heritage, spiritual philosophy, and universal message of peace and unity associated with Khwaja Garib Nawaz (RA).

Modern Interface: Deliver a clean, accessible layout that functions seamlessly across modern web browsers, smartphones, and tablets.

✨ Detailed Key Features

1. Interactive Homepage & Vision

Introduction & History: An engaging overview highlighting the life, universal teachings, and historical impact of Khwaja Garib Nawaz.

Core Philosophy: Dedicated sections explaining key values such as selfless service (Khidmat), charity (Langar), and harmony.

2. Comprehensive Visitor Guide

Dargah Timings & Daily Rituals: Clear information on opening and closing hours, prayer schedules, and daily ceremonies.

Visitor Etiquette & Guidelines: Essential guidance for first-time pilgrims covering attire, code of conduct, and offerings.

Directions & Nearby Landmarks: Practical information for travelers, including local navigation cues within Ajmer.

3. Media & Architectural Showcase

Photo & Architecture Gallery: A visual walk-through highlighting the intricate Islamic architecture, historical gates (e.g., Nizam Gate, Buland Darwaza), and courtyards.

Spiritual Traditions: Explanations of traditional practices such as Qawwali gatherings, Langar distribution, and annual Urs celebrations.

4. Community & Interactive Portal

Inquiry & Feedback Form: A simple, web-based contact form allowing users to send feedback, ask questions, or request guidance.

Frequently Asked Questions (FAQ): A helpful reference covering common queries about visits, transport, accommodation, and safety protocols.

🛠️ Technology Stack & Architecture

This application was constructed using foundational frontend web development technologies, focusing on clean structure, semantic code, and lightweight performance:

Markup Language: HTML5

Built using semantic HTML elements (<header>, <nav>, <main>, <section>, <footer>) to ensure good readability and basic accessibility.

Styling & Layout: CSS3

Utilizes CSS flexbox/grid for layout structures.

Custom styling rules for typography, soft color palettes suited for a spiritual theme, and responsive breakpoints.

Interactive Behavior: JavaScript (ES6)

Lightweight client-side scripts used for interactive elements such as responsive navigation menus, image gallery modals, and form validations.
